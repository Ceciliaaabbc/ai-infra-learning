对，**`model.py` 和 `train.py` 是项目 0 的核心**。不过还有一个 `perf.py` 也算核心代码，`train.py` 里的计时、MFU、显存估算都是靠它算的。其他文件大多是工具、学习材料，或者实验结果。

## 每个文件的作用

**1. 核心代码**

| 文件 | 作用 |
|---|---|
| `model.py` | 模型本身：定义 GPT-2 怎么从 token 一步步算出 loss |
| `train.py` | 训练脚本：把模型跑起来，并测量速度 |
| `perf.py` | 测量工具：计算 FLOPs 和 MFU、估算显存、计时，供 `train.py` 调用 |

**2. 运行实验前的准备**

| 文件 | 作用 | 什么时候用 |
|---|---|---|
| `requirements.txt` | 列出需要安装的 Python 包（torch、numpy、tiktoken） | 到新机器上，第一步先 `pip install -r requirements.txt` |
| `check_gpu.py` | GPU 环境自检：检查 bf16、TF32、FlashAttention 等功能能不能用，并实测显卡算力 | 每次租到新显卡后先跑一下 |
| `prepare_data.py` | 下载莎士比亚文本，转成 token 编号，存成 `data/shakespeare/train.bin` | 跑实验之前运行一次 |

**3. 批量跑实验、汇总结果**

| 文件 | 作用 |
|---|---|
| `run_experiments.sh` | 一键跑完 11 组实验，每组用不同的开关组合调用 `train.py` |
| `report.py` | 把 `results.csv` 整理成一张 Markdown 表格，可以直接贴进博客 |

**4. 学习材料**

| 文件 | 作用 |
|---|---|
| `learn/01_tensor.py` | PyTorch 入门：tensor、形状、数据类型 |
| `learn/02_autograd.py` | 自动求导、计算图、梯度累加 |
| `learn/03_train_loop.py` | 一个最小的训练循环（训练五步） |
| `learn/04_attention.py` | 用 3 个词手算一遍 attention |
| `docs/model_explained.md` | `model.py` 详解，配有 3 张流程图 |
| `docs/train_explained.md` | `train.py` 详解，配有 3 张流程图 |
| `docs/images/` | 上面两份文档用到的 6 张图 |

**5. 实验结果**

| 文件 | 作用 |
|---|---|
| `results/rtx4090/results.csv` | 4090 上 11 组实验的原始数据 |
| `results/rtx4090/ladder.log` | 完整的运行日志，每一步的 loss、耗时都在里面 |
| `results/rtx4090/README.md` | 结果分析：每项优化为什么有效，瓶颈在哪里 |

**6. 说明和配置**

| 文件 | 作用 |
|---|---|
| `gpt-perf-lab/README.md` | 项目 0 的使用说明：怎么跑、指标是什么意思、每个实验改了代码的哪里 |
| 根目录的 `README.md` | 整个仓库的首页：项目路线和阅读顺序 |
| `.gitignore`（两个） | 告诉 git 哪些文件不用提交，比如下载的数据、临时文件 |

## 这些文件是怎么串起来的

在 GPU 服务器上跑一次完整实验，用到的文件依次是：

```
requirements.txt   安装依赖
      ↓
check_gpu.py       检查显卡
      ↓
prepare_data.py    准备数据 → 生成 data/shakespeare/train.bin
      ↓
run_experiments.sh 批量跑实验
      ↓  （调用 train.py 11 次；train.py 又会用到 model.py 和 perf.py）
results.csv        每次实验追加一行结果
      ↓
report.py          整理成表格
```

## 运行时才会生成的文件（不在仓库里）

这些在 `.gitignore` 里，不会提交到 GitHub：
- `data/`：`prepare_data.py` 下载和处理后的数据。
- `traces/`：用 `--profile` 跑出来的时间线文件。
- `gpt-perf-lab/` 下直接生成的 `results.csv` 和 `ladder.log`：这是跑实验时的工作文件。整理好的结果放在 `results/rtx4090/` 里。

另外，本地还有两个不在仓库里的东西：
- 根目录的 `gpt-perf-lab.zip`：之前打包给你上传服务器用的，被 `.gitignore` 忽略了。现在代码可以直接从 GitHub clone，这个压缩包已经用不上了。
- `gpt-perf-lab/readme_ask/`：这个文件夹是你自己建的，还没有提交到 git。

## 学习时的优先级

1. **必须读懂**：`model.py`、`train.py`。
2. **值得一读**：`perf.py`。它很短，MFU 是怎么算出来的、为什么每个参数占 16 字节，都在这里。
3. **会用就行**：`check_gpu.py`、`prepare_data.py`、`run_experiments.sh`、`report.py` 这些工具，知道什么时候用、怎么用就够了。
